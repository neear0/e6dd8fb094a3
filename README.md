# BESOL AGENCY: návrhy redizajnu

Tri statické návrhy nového webu pre besol.sk (rebrand na BESOL AGENCY).

- `a/` Fasáda: svetlý, referencie ako vzorkovník fasád
- `b/` Termo: tmavomodrý, interaktívny termovízny dom
- `c/` Lešenie: priemyselný, dôraz na požičovňu lešenia a techniky

Úvodná stránka `index.html` slúži na výber. Stránky sú čisté HTML/CSS bez build kroku, fotky sú prevzaté z besol.sk (`assets/img`).
